# The Other Hand

Website for *The Other Hand* podcast, hosted by Jeremy Newman. Live at https://theotherhandpodcast.com.

- `index.html` is the whole site: content, styles, and scripts.
- `images/` holds the artwork and headshot.
- Netlify deploys automatically on every push to `main`. There is no build step.
- Both forms send to theotherhandpodcast@gmail.com through FormSubmit (formsubmit.co).

Brand: Deep Navy #14202E, Stormcloud #3C4A5E, Gold Leaf #B7935F, Sand #D5CBB8, Linen #EFE9DC. Newsreader for headlines, IBM Plex Sans for body, IBM Plex Mono for timestamps.
